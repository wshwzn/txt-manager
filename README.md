# txt-manager

一个**零依赖**的本地纯文本文件管理器。Node.js 单文件后端 + 内嵌前端，双击即用，不装任何东西、不联网。

为「把一堆 txt / sql / js 小文件堆在同一个文件夹里、需要随手翻看和改两笔」这种场景做的。

## 功能

- **左侧文件列表 + 右侧查看/编辑**：列表支持搜索，按修改时间倒序
- **Ctrl+S 保存**，有未保存改动时列表项带小圆点、文档头显示提示，切换文件前会拦截确认
- **UTF-8 / GBK 编码自动识别**：GBK 文件保存时统一转存为 UTF-8
- **日间 / 夜间主题**一键切换
- **左侧栏宽度可拖动**（160~640px，双击恢复默认）
- **正文字号 9 档可调**（12~24px）：只影响正文，不影响左侧目录字号，所以两者的相对大小关系可调；整体大小仍可用浏览器自带的 Ctrl+滚轮缩放
- **自动折行开关**：长行可选换行显示或横向滚动
- **一键显示 / 隐藏文件名后缀**
- **新建 / 删除文件**，删除走 Windows 回收站，可恢复
- **二进制文件保护**：含 NUL 字节的文件（.lnk / .exe / 图片等）判定为非文本，只提示、禁止编辑，避免误保存损坏文件
- **一键切换工作目录**，记住最近使用的 8 个目录；目录选择器是页面内置的，不依赖系统对话框
  - 「最近使用」里的每一条右侧都有 `×`，可以从历史里移除（只删记录，不会动磁盘上的文件夹，也不影响当前目录）

所有界面偏好（主题、后缀显示、侧栏宽度、正文字号、折行）都记在浏览器 localStorage 里，刷新后保持。

## 运行环境

- **Windows**：删除到回收站、盘符枚举等依赖 Windows
- **Node.js 18+**：不需要 `npm install`，本项目零第三方依赖

## 启动

双击 `start.bat`，浏览器会自动打开 <http://127.0.0.1:5177>。

或手动启动：

```
node server.js
```

服务只监听 `127.0.0.1:5177`，不对外开放。重复运行会提示「已在运行」并直接打开页面，不会报错。

## 目录结构

```
doc-manager\
├── server.js        后端服务 + 内嵌前端页面（单文件）
├── start.bat        启动器
├── config.json      运行时配置（自动生成，已 gitignore）
└── README.md
```

## 关于 config.json

程序**只在启动时读一次** config.json，之后全程使用内存里的副本：

```json
{
  "dir": "文档目录的绝对路径",
  "recent": ["最近使用过的目录，最多 8 个"]
}
```

它只在两种情况下被写盘：**切换工作目录**时，以及**从「最近使用」里移除一条记录**时。由此带来两个要知道的现象：

1. **删掉 config.json 后不重启服务，历史目录依然在**——数据在内存里，文件删了不影响运行中的进程；而且只要你再切换一次目录，它就会被重新写回磁盘。
2. **想真正清空配置，必须「删文件 + 重启服务」两步一起做**。只删不重启会白删，只重启不删会读回来。

清空后 `dir` 会回落到默认值（程序自身所在目录），`recent` 变空。

首次运行若没有 config.json，默认工作目录就是**程序所在目录**，因此不需要任何初始化步骤。

## 实现说明

- **零依赖**：只用 Node 内置的 `http` / `fs` / `path` / `vm` / `util`，前端也是原生 JS，没有构建步骤。
- **单文件**：整个前端页面以模板字符串形式内嵌在 `server.js` 里，由服务端直接吐出，不需要静态资源服务器。
- **启动自检**：启动时会用 `vm.Script` 对页面脚本做一次语法解析（不执行），避免前端脚本出错导致「整页交互失效」却悄无声息。
- **防目录穿越**：所有文件操作都经 `safeResolve()` 把路径解析后校验必须落在工作目录内。
- **删除到回收站**：通过 PowerShell 调用 `Microsoft.VisualBasic.FileIO.FileSystem` 把文件移入回收站，而不是永久删除；成功判据是「文件已从磁盘消失」，而非看子进程退出码。

## 快捷键

| 快捷键 | 作用 |
|---|---|
| `Ctrl + S` | 保存当前文档 |
| `Ctrl + 滚轮` | 浏览器原生整页缩放（会等比缩放正文与目录，两者相对比例不变） |
